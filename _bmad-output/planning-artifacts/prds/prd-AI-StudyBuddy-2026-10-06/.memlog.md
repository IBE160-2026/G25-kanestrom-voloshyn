- (decision) UJ-1 (first-time use), persona Emma, biology student: creates account -> starts a named project (e.g. 'Biology - Cell Division') -> uploads lecture slides/PDFs -> project shows 4 options (Quiz, Flashcards, Summarize, Ask AI/chat) -> takes Quiz -> gets immediate per-question feedback with explanations grounded in the material -> sees end score + incorrect answers -> wrong answers auto-saved to Mistake Review. - (decision) UJ-2 (returning use), same persona: logs back in -> opens saved project -> uploaded material + prior activity still present -> project surfaces a mistake-count indicator (e.g. '3 mistakes to review') -> student opts in to open Mistake Review and practice those specific missed questions. V1 rule: mistakes auto-saved and clearly surfaced, but review is student-initiated, not forced/pushed.

- (decision) Ask AI defaults to answering from all material in the Project; student can optionally narrow to one specific uploaded document.
