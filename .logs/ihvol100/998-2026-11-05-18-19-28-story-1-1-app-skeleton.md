### Resultat
- **Branch:** `feature/app-skeleton`, commit `07206870f3ce41019129d72f71e44d83bebd20cd` (not pushed, not merged).
- **Built:**
  - uv async FastAPI on Python 3.14 with one worker: `/api/config`, a JSON `not_found` catch-all, docs under `/api/docs`, and the SPA via `app.frontend`.
  - `LLM_MODE` resolution per AD-4.
  - create-vite React with `tokens.css` from DESIGN.md, bundled Inter, and a wordmark-only Login placeholder.
  - `supabase init` with the AD-2 auth settings, and CLI 2.122.0 pinned.
  - A multi-stage Dockerfile and compose; compose sets the container's Supabase and DB URLs.
  - `.env.example`, plus a Norwegian "Kjør lokalt" section in README.
- **Verified:** 38 pytest tests pass against local Supabase; `npm run build` works; only `tokens.css` has hex colours; `docker compose up --build` serves the config JSON, the JSON 404, `index.html` for deep links, and logs the mock-mode warning.
- **Review:** 8 patches applied (error-envelope, lifespan and LLM-mode tests; compose URL override; docs under `/api`; HTTP headers kept; Vite proxy on 127.0.0.1; favicon). 2 deferred, 19 rejected, all logged in the spec's triage log.
- **Decision (Ihor):** `.env.example` may ship `SUPABASE_AUTH_EXTERNAL_GOOGLE_ENABLED=false`, because the Supabase CLI fails on an empty value.
- **Behaviour to know:** `app.frontend` returns `index.html` only for requests with `Accept: text/html` (browsers). A plain `curl` on a deep link gets the JSON 404.
- **Sprint status:** Story 1.1 → `review`.
