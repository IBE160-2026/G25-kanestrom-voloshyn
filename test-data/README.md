# test-data

Small, self-written sample files for tests and manual checks. Every file here was written or generated by the team for this project and is free to use (CC0). Never add textbooks, course PDFs, or lecture slides (AGENTS.md).

## The test document

`photosynthesis-notes.md` is **the test document** the PRD refers to. The same text, split into 8 sections, is also available as `photosynthesis-lecture.pdf` (8 pages), `photosynthesis-lecture.pptx` (8 slides), and `photosynthesis-notes.docx`.

- **SM-4 runnable check.** Upload `photosynthesis-lecture.pdf` to a new Project, generate a Quiz of 10 questions from all Topics, and answer them. For each question, open the source it names (page N) and check that the page contains the answer. At least 9 of 10 must pass. Two team members check independently and note the result.
- **FR-16 "not in the material".** Ask a question the notes don't cover and check that the chat says so and makes no factual claim. Use these questions:
  - "How does the human liver store glycogen?" (biology, but not in the notes)
  - "What is the capital of Australia?" (off-topic)
  - "Which year did Melvin Calvin die?" (the notes name Calvin but don't give this)
- **FR-29 material language.** `fotosyntese-notater.md` is a short Norwegian version. Generated content from it must be in Norwegian, even with the interface in English.

## Images (FR-7)

In mock mode, `extract_image_text` picks its fixture from a marker in the file name (AD-4), so these three give the three outcomes with no key. In live mode, the pictures are drawn to match: clear, half covered, and blurred.

| File | Mock outcome |
| --- | --- |
| `notes-photo.png` | readable → accepted |
| `notes-photo-partial.png` | partial → accepted with warning |
| `notes-photo-unreadable.png` | unreadable → rejected |

There is no `.heic` sample, because it can't be made without an Apple device. Add one from a team member's own phone if a HEIC test is needed.

## Not stored here

Files that are only big, such as a file over 50 MB or a text long enough to exceed the context budget or the 100-Topic ceiling, are generated inside the tests, so the repository stays small.

## Rebuilding the binary files

The PDF, PPTX, DOCX, and PNG files are generated from the text files by `make_samples.py`. After changing the notes, run this from the repo root:

```sh
uv run --no-project --with fpdf2 --with python-docx --with python-pptx --with pillow python test-data/make_samples.py
```
